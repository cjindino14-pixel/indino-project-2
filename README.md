# Kabankalan Catholic College (KCC) Website

A responsive multi-page KCC-themed website adapted from the uploaded Bootstrap template.

## Pages
- `index.html` — Home
- `about.html` — About, vision, mission, and values
- `courses.html` — College programs and Senior High School tracks
- `trainers.html` — Administrators (filename preserved from the template)
- `events.html` — Campus life and selected KCC activities
- `pricing.html` — Fees and enrollment information
- `contact.html` — Contact details and map
- `course-details.html` — Program information page

## How to open
1. Extract the ZIP file.
2. Open the folder in Visual Studio Code.
3. Open `index.html` in a browser, or use the VS Code Live Server extension.
4. Keep the `assets` folder beside the HTML files.

## Notes
- The site uses the Bootstrap files already included in `assets/vendor`.
- The KCC custom theme is in `assets/css/kcc-custom.css`.
- KCC information is based on public information available from the official website and public education references. Course availability, titles, tuition, contact numbers, and school schedules should be confirmed with KCC before real-world use.
- The administrators page uses representative stock photos and office descriptions rather than invented staff identities.
- Some KCC historical/event photographs and stock photos load from external image hosts and require an internet connection.
- The contact form uses `mailto:` and opens the visitor's email application. It is a front-end demo, not a server-side form handler.
